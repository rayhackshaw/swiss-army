# Swiss Army Knife

A collection of commonly used utilities of mine all in one place.

Previously I used to just look these up online whenever I needed them. Eventually I decided I would just bundle them all together for myself.

## Tools

- **Text Compare** — Compare two blocks of text side by side
- **JSON Prettify** — Format and prettify JSON
- **SQL Highlighter** — Syntax highlighting for SQL queries
- **Typing Speed Test** — Test your typing speed
- **Reaction Speed** — Test your reaction time
